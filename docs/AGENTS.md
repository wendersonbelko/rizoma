# docs

The documentation site (VitePress) is pt-BR. Instruction files for agents stay English.

## When you change the product

Update the page that describes the screen you changed. Quote the real label, route, and query key.

- App routes and query keys in examples are English (`/invite/<token>`, `?s=organization`, `?tab=rules`).
- Doc-site paths stay Portuguese (`/admin/pessoas-e-acesso`, `/uso/catalogo`). Those paths are what the reader opens.
- A sample slug a person would type (a service named `pedidos-api`) may stay Portuguese. A code identifier may not.

## What not to invent

- Do not rewrite a screenshot path. If the picture is stale, say so in the surrounding text or leave the picture and fix the false sentence.
- Do not add a page that is not linked from the sidebar.
- Match button and screen names to the UI. If you rename a label, update the tour copy and the doc page in the same change.
