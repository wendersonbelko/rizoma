# Como contribuir

O texto completo está em [docs/contribuindo/index.md](docs/contribuindo/index.md): bugs, sugestões, documentação, código e revisão.

O caminho curto:

1. Leia [docs/contribuindo/ambiente.md](docs/contribuindo/ambiente.md) e deixe o hub rodando.
2. Crie uma branch a partir da `main`.
3. Siga [docs/contribuindo/padroes-de-codigo.md](docs/contribuindo/padroes-de-codigo.md).
4. Rode `pnpm lint`, `pnpm typecheck` e `pnpm test`.
5. Abra o pull request como em [docs/contribuindo/pull-requests.md](docs/contribuindo/pull-requests.md).

A licença das contribuições é a [MIT](LICENSE). A conduta está em [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Vulnerabilidade não vai em issue pública: veja [SECURITY.md](SECURITY.md).
